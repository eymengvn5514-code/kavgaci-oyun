# 1. FROZman — Buz

**Görünüm:** Mavi-beyaz zırh, buz kristali omuzluklar, gözlerde buz mavisi parlama. Nefesinde soğuk buğu.

**Stats:** HP ▓▓▓▓▓▓▓░░░ · ATK ▓▓▓▓▓░░░░░ · SPD ▓▓▓▓░░░░░░ · RANGE ▓▓▓▓▓▓░░░░ · Zorluk: Kolay

**E — Buz Püskürtme** `18s → 16s`
- Ağzından yakın mesafeye buz püskürtür.
- **Kamera yakın çekime girer** (karakterin ağzı odak).
- Rakip **1.5 saniye donar** → donmuşken vuramaz, hareket etmez, skill atamaz.
- Kısa menzil, ama garanti kurulum (combo açıcı).

**C — Buz Kılıcı** `27s → 20s`
- Elinde buzdan kılıç oluşur. Uzunluk: **tekme mesafesi kadar** (~1 adım, fazla uzun değil).
- **7 saniye** elde kalır. Kesince ekstra buz hasarı + hafif yavaşlatma.

**Q — Buz Zırhı** `22s → 18s` · süre **6s**
- Etrafını buz kabuğuyla kaplar.
- Gelen hasarın **%40'ını emer** (yutar).

**R — Ultimate: Absolute Zero** `26s` (can < %50)
- Alanı dondurur; çevredeki herkesi **2.5s** dondurur + ağır hasar.

# 2. Volt — Yıldırım

**Görünüm:** **Mavi gözler**, başında **oval (konik) hasır şapka** (ai-ri). Vücudunda yıldırım dolaşan çizgiler.

**Stats:** HP ▓▓▓▓▓▓░░░░ · ATK ▓▓▓▓▓▓▓░░░ · SPD ▓▓▓▓▓▓▓░░░ · RANGE ▓▓▓▓▓▓▓░░░ · Zorluk: Orta

**E — Gökten Yıldırım** `17s → 15s`
- Rakibin üstüne havadan yıldırım çarpar.
- **1 saniye sersemletme.** Sersemken **vuruşlar yavaşlar** (oyuncu hızlı bassa bile işlemez — input throttle).

**C — Elektrikli Şapka Fırlatma** `25s → 20s`
- Şapkasını yıldırımla elektrikleyip rakibe fırlatır.
- Hasar + rakibin **içine elektrik girer (6 saniye)**.
- Bu sürede Volt'un **tüm vuruşları %25 daha fazla hasar** verir.

**Q — Yıldırım Şeridi** `22s → 18s`
- Önünden map sonuna kadar **şerit halinde yıldırımlar** (şema):
  `Sen | /  /  /  /  /  /  /  /  /  /  → map ucu`
- Şeride değen **1.5s sersemler**.

**R — Ultimate: Fırtına** `26s` (can < %50)
- Tüm arenaya yıldırım yağmuru; değenler sersemler + hasar.

# 4. Ghost — Hayalet

**Görünüm:** Yarı saydam beyaz-mavi beden, dalgalanan pelerin, yüzünde boş mavi ışık. Arkasında ürkütücü afterimage izi.

**Stats:** HP ▓▓▓▓▓░░░░░ · ATK ▓▓▓▓▓▓▓░░░ · SPD ▓▓▓▓▓▓▓▓░░ · RANGE ▓▓▓▓▓▓░░░░ · Zorluk: Zor

**E — Ölüm Işınlanması** `18s → 15s`
- Rakibin **arkasına ışınlanır** → rakibi **havaya fırlatır** → Ghost **havaya ışınlanıp** rakibi yere çakar.
- Yüksek hasar, ana kombo başlatıcı. (Hasar değerlerini sonra inceleyeceğiz — bunu denge notu olarak işaretle.)

**C — Kabin Ghost'u + Kılıç** `24s → 19s`
- Ghost **içinden bir ghost daha çıkarır** (kabinden) → o ghost kılıçla rakibe koşar → **kılıcı rakibin içine bırakır**.
- Oyuncu **kılıcı alıp 6 saniye** kullanabilir. Süre bitince kılıç yok olur.

**Q — 4 Yönlü Klon** `28s → 22s`
- Klonlar 4 yönden koşup saplar:
  - 1 klon → **kalbe** kılıç
  - 1 klon → **üstten, havadan**
  - 1 klon → **sağdan**
  - 1 klon → **soldan**
- Bu klonların kılıcı **alınamaz** (sadece hasar).

**R — Ultimate: True Phantom** `28s` (can < %50)
- Ghost bedeni bölünür, ekran kararır, 5 klon aynı anda saldırır.

**R — Ultimate: Horde** `26s` (can < %50)

## Denge Notları (sonra inceleyeceğiz)

- **Donma / sersemletme süreleri:** 0.5s (zombie baby) → 1s (Volt E) → 1.5s (FROZman E, Volt Q) → 2–2.5s (ultimeler). Süre arttıkça hasar azaltılmalı.
- **Kamera yakın çekimleri:** FROZman E, Blaze E, Volt E gibi "spell" skillerinde 0.4–0.8s cinematic.
- **Ultimate kapısı:** tüm karakterlerde can < %50. Bazılarına ek olarak "meter" de eklenebilir.
- **Hasar değerleri:** henüz sayı yok → Faz 4'te (ilk 5 karakter oynanabilir olunca) bir tablo yapıp ölçekleyeceğiz.
